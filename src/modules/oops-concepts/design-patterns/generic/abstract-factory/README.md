# Abstract Factory — Generic

Full theory and interview questions:
[`../../backend/abstract-factory/README.md`](../../backend/abstract-factory/README.md)

The classic framing: a coffee shop serves hot drinks in paper cups with lids, and cold drinks in
plastic cups with straws. The two components must match. An abstract factory guarantees you never
end up serving iced coffee with a lid.

| Example | Scenario |
| --- | --- |
| `example1` | `HotDrinkFactory` and `ColdDrinkFactory` producing matched drink + cup pairs |
| `example2` | `IndiaKit` and `UsKit` producing matched identity + payroll + benefits |
